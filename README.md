# Calmar
## Linux Markdown notes with Git-backed history.

Your notes are plain `.md` files, in a folder you choose. Every change becomes a Git commit in that folder.

## Why ?

I used Trilium for years to keep my notes. But I wanted something more simple.
The notes can be linked to each other using Markdown links.

## Status

Early. Nothing interessant yet !
